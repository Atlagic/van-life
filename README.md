# VanLife App

VanLife is a React-based web application that allows users to explore camper vans available for rent. The app focuses on modern React patterns such as React Router, loaders, nested routes and protected routes, while providing a clean and intuitive user experience.

Users can browse vans, filter them by type, view detailed van information, and manage host-specific content through authenticated routes.

**Key Features**

- React component architecture – modular, reusable UI components
- State management – dynamic updates for listings, filters, and user interactions 
- Firebase integration – authentication, database operations, and real-time updates 
- Interactive UI – responsive search, filters, and booking interface 
- Conditional rendering – personalized dashboards and protected routes

**Tech Stack**

- React
- React Router
- JavaScript (ES6+)
