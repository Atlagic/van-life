# VanLife App

VanLife is a React-based web application that allows users to explore camper vans available for rent. The app focuses on modern React patterns such as React Router, loaders, nested routes, and protected routes, while providing a clean and intuitive user experience.

Users can browse vans, filter them by type, view detailed van information, and manage host-specific content through authenticated routes.

**Key Features**

Van browsing and filtering
Dynamic routing with React Router
Route loaders for data fetching
Protected routes for host pages
Clean, component-based UI

**Tech Stack**

React
React Router
JavaScript (ES6+)
